## Extract these files to the OldTanks Online game folder.
- **StandaloneLoader.swf**: Load Prelauncher.swf from the current directory
- **Prelauncher.swf**: Load resources from https://networkpenetrationtester.github.io/oldtanksonline-2013-resources/
- MAKE SURE YOU CLEAR YOUR CACHE BEFORE LOADING THE GAME!
- Contact networkpenetrationtester on Discord if you spot something inconsistent with 2013 textures.
